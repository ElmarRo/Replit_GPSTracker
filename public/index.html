Required Libraries

TinyGPSPlus

Lightweight GPS parsing library. Install via Arduino Library Manager.

Sketch > Include Library > Manage Libraries > Search "TinyGPSPlus"

LiquidCrystal_I2C

LCD display driver for I2C backpack modules.

Sketch > Include Library > Manage Libraries > Search "LiquidCrystal I2C"

SoftwareSerial

Built-in Arduino library for serial communication on digital pins.

Included with Arduino IDE (no installation needed)

Setup Notes

GPS Module Tips

  • First fix can take 1-15 minutes outdoors
  • The antenna must have clear sky view
  • LED on module blinks when fix is acquired
  • Default baud rate is 9600

LCD I2C Address

  • Common addresses: 0x27 or 0x3F
  • Run I2C scanner sketch if display is blank
  • Adjust contrast via potentiometer on back
  • Backlight can be toggled via jumper

Power Considerations

  • GPS module draws ~50mA at 3.3-5V
  • LCD backlight draws ~20mA
  • USB power is sufficient for testing
  • Use external 7-12V for standalone use

Troubleshooting

  • No GPS data? Check TX/RX connections
  • LCD blank? Check I2C address and contrast
  • Garbled data? Verify baud rate is 9600
  • No fix? Move outdoors with clear sky
